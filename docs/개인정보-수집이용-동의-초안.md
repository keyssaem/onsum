# 개인정보 수집·이용 동의 (초안)

> ⚠️ **이 문서는 개발자가 작성한 초안입니다.**
> 실제 서비스 개시 전 **충청남도청양교육지원청 개인정보 보호 담당자의 검토·승인**을 받아야 합니다.
> 대괄호 `[ ]` 부분은 기관 실정에 맞게 채워 주세요.

---

## 1. 입력란 아래에 바로 보이는 짧은 문구 (체크박스 라벨)

```
☐ (필수) 개인정보 수집·이용에 동의합니다.   [전문 보기]
```

체크박스 바로 아래 회색 작은 글씨 1줄:

```
성명은 플랫폼 이용 현황 파악 목적으로만 수집하며, 수집일로부터 1년 후 파기합니다.
```

---

## 2. [전문 보기]를 눌렀을 때 나오는 전체 안내문

### 개인정보 수집·이용 동의서

「개인정보 보호법」 제15조 제1항 제1호에 따라, 학생 상담지원 플랫폼 **함께 온(溫)숨**
이용을 위한 개인정보 수집·이용에 대해 아래와 같이 안내드립니다.

| 구분 | 내용 |
|---|---|
| **수집 항목** | 성명(실명) 1개 항목 |
| **수집·이용 목적** | ① 플랫폼 이용자 확인 <br> ② 자료 이용 현황 파악 및 통계 산출을 통한 서비스 개선 |
| **보유·이용 기간** | 수집일로부터 **1년** (기간 경과 시 지체 없이 파기) |
| **수집 방법** | 이용자가 입장 화면에서 직접 입력 |

**■ 동의를 거부할 권리 및 거부에 따른 불이익**
귀하는 위 개인정보 수집·이용에 동의하지 않을 권리가 있습니다.
다만 동의하지 않으시는 경우 플랫폼 이용이 제한됩니다.

**■ 수집하지 않는 정보**
본 플랫폼은 성명 외에 주민등록번호, 연락처, 이메일, 소속 학교명, 담당 학생 정보 등
어떠한 정보도 수집하지 않습니다. 또한 상담 내용이나 학생 개인정보를 입력하는 기능이 없습니다.

**■ 개인정보의 제3자 제공 및 처리 위탁**
수집된 정보는 제3자에게 제공하지 않습니다.
다만 데이터 보관을 위해 아래와 같이 처리를 위탁하고 있습니다.

| 수탁자 | 위탁 업무 | 보관 위치 |
|---|---|---|
| Supabase, Inc. | 데이터베이스 보관 | [ 예: 대한민국 서울 리전 / 싱가포르 리전 ] |

**■ 정보주체의 권리**
귀하는 언제든지 본인의 개인정보에 대한 열람·정정·삭제·처리정지를 요구할 수 있으며,
충청남도청양교육지원청으로 요청하시면 지체 없이 조치합니다.

처리기관: 충청남도청양교육지원청
시행일: [ YYYY. MM. DD. ]

## 3. 개발 시 함께 지켜야 할 기술적 조치

계획서(`PLAN.md` §3)에 반영되어 있으며, 위 안내문의 내용을 실제로 지키기 위한 항목입니다.

- [ ] **최소 수집** — 성명 외 어떤 항목도 저장하지 않음 (IP·기기정보·접속기록 저장 안 함)
- [ ] **접근 통제** — RLS로 익명 사용자는 기록 추가만 가능, 조회 불가
- [ ] **보유기간 자동 관리** — 1년 경과 데이터 자동 삭제 (Supabase 예약 작업)
      ```sql
      delete from access_logs where entered_at < now() - interval '1 year';
      ```
- [ ] **전송 구간 암호화** — 전 구간 HTTPS (GitHub Pages · Supabase 모두 기본 제공)
- [ ] **동의 없이는 입장 불가** — 체크박스 미선택 시 입장 버튼 비활성화
- [ ] **데이터 보관 위치 확인** — Supabase 프로젝트 생성 시 리전 선택 필요.
      공공기관 지침상 국내 보관이 요구될 수 있으므로 **Seoul(ap-northeast-2) 리전 선택 권장**

> 📌 **Supabase 프로젝트를 만들 때 리전을 반드시 확인하세요.**
> 한 번 정하면 나중에 바꿀 수 없고, 위 안내문의 "보관 위치" 항목과 직결됩니다.
